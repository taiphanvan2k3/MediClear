# MediClear Workspace Agent Rules & Design System Standards

All development and design work in this workspace MUST strictly adhere to the official Competition Judging Criteria and Design System documented in [GEMINI.md](file:///d:/SelfLearning/AIRiser2026/MediClear/GEMINI.md):

1. **Feasibility (40%)**:
   - High accessibility & readability for seniors & all age groups.
   - Clean, bug-free, fully functional React code (`tsc --noEmit` must pass cleanly).
   - "Clinical Modern Wellness" visual style with high WCAG AAA contrast.

2. **Impact (30%)**:
   - Solve real healthcare pain points: medication error prevention, prescription readability, emergency SOS contact.
   - Scalable architecture for health records and Google Cloud integration.

3. **Creativity (30%)**:
   - Leverage Google Gemini AI Multimodal inference for medical document scanning.
   - Seamless integration with Google Calendar API for automated medication reminders.
   - Personalized AI persona and pronouns (Bác ↔ Cháu).

4. **Design System & Color Palette**:
   - **Base**: Crisp White (`#FFFFFF`) & Soft Warm Greys (`slate-50`, `slate-100`, `slate-200`).
   - **Primary**: Mint Green (`emerald-600`, `emerald-500`, `emerald-50`).
   - **Secondary**: Cerulean Blue (`sky-600`, `sky-500`, `sky-50`).
   - **Alerts**: Soft Amber (`amber-50`, `amber-800`) & Coral Red (`rose-50`, `rose-600`).
   - **Mobile UX**: Toast at `bottom-20`, Login Gate when unauthenticated, dual camera/album photo buttons.
